# Apple Software Licenses

This repository provides an archive of Apple software licenses and acknowledgments. Eventually the goal is to have the licenses and acknowledgments from all Apple operating systems including macOS, OS X, Mac OS X, iOS, iPadOS, etc. The goal is to preserve these documents so we can see how they change over time.

## Purpose

This project aims to:

- Document how Apple software licenses evolve over time.
- Provide a centralized archive for historical reference.

## Contributing

If you have access to historical Apple software licenses or acknowledgements files that are not currently in this repository, please add them!

On modern versions of macOS, these files can be found at the following locations:
- PDF versions of the license and the `Acknowledgements.rtf` file is located at `/Library/Documentation`.
- HTML and Rich Text Format (RTF) versions are located at `/System/Library/CoreServices/Setup Assistant.app/Contents/Resources/en.lproj`.
